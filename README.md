# Xona TSA

Application web mobile-first pour la vente d'événements et de tickets numériques.

## Structure

```
index.html      Écran de démarrage
login.html      Connexion (e-mail ou téléphone)
signup.html     Création de compte (e-mail ou téléphone)
css/style.css   Styles partagés
js/app.js       Interactions (onglets, mot de passe, validation)
assets/         Logo et éléments graphiques
```

## Lancer en local

Ouvrir `index.html` dans un navigateur, ou servir le dossier avec un serveur statique.

## Déploiement

Compatible GitHub Pages : pousser le contenu de ce dossier à la racine du repo (ou dans `/docs`) et activer Pages sur la branche correspondante.
